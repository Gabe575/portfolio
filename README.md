# Gabriel Santos - Web Portfolio

## Overview

This is my personal web portfolio built with Next.js, TypeScript, and Tailwind CSS.
It features a custom 3D particle animation, server-side form handling, and rate-limited email delivery.
The site showcases my projects, skills, and includes a contact form with social links.

This project was a chance for me to experiment with server actions, rate limiting strategies, custom Three.js components and more in a real world app.

Live demo: https://www.gabesantos.ca

### Built With

- [Next.js](https://nextjs.org)
- [React](https://react.dev)
- [Tailwind CSS](https://tailwindcss.com)
- [Three.js](https://threejs.org) (for the hero animation)
- [Upstash Redis](https://upstash.com) (rate‑limiting)
- [Resend](https://resend.com) (email service)
- [Vercel](https://vercel.com) (web hosting)

## Features

- Sticky navbar that hides on scroll
- Dark/light theme toggle (next‑themes)
- Contact form with server‑side validation, rate limiting, and spam honeypot
- Scrolling language/framework marquee animations
- Fully responsive layout
- 3D particle title animation rendered with Three.js/React‑three‑fiber
